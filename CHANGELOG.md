# Історія змін (Changelog)

Усі суттєві зміни у проєкті **UAV Readiness & Evidence Copilot (`shmlv. systems`)** документуються в цьому файлі.
Формат базується на [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/), версіонування відповідає [Semantic Versioning](https://semver.org/lang/uk/).

## [2.5.0] - 2026-10-21

### Додано
- **Епістемічний захист від порожніх та неповних даних (`Zero-Evidence Ceiling = 0/100`)**: у TypeScript-ядрі (`@uav-readiness/rules`), браузерному калькуляторі (`docs/tools-engine.js`) та пакетному верифікаторі (`docs/multi-file-verifier-bundle.js`) пакети без підтверджених артефактів, порожні файли (`0 B`), таблиці лише з заголовком (`header-only CSV/XLSX`) та поодинокі 2-стовпцеві документи без пари для крос-звірки примусово отримують статус `UNVERIFIED` (`0/100 · НЕДОСТАТНЬО ДАНИХ / НЕ ОЦІНЕНО`) замість хибного `PASS`.
- **Детермінована дедуплікація за `SHA-256` та режими верифікації (`CROSS_DOCUMENT`, `INTERNAL_CONSISTENCY`, `SINGLE_SOURCE_UNVERIFIED`)**: виявлення перейменованих копій одного файла (`DUPLICATE_FILE_SHA256`) та повне вилучення самоклонування одного джерела.
- **Структурний `ASN.1 DER` парсер `.p7s` (`CMS SignedData`, RFC 5652)**: перевірка ієрархії `ContentInfo -> SignedData`, прив'язка сертифіката підписувача через `SignerInfo.sid` (`IssuerAndSerialNumber` / `SubjectKeyIdentifier`), витягування X.509 RDN-атрибутів виключно з дерева сертифіката та явне розмежування `structuralStatus: "PASS" | "FAIL"` і `cryptoStatus: "UNVERIFIED"` (`UNVERIFIED_CRYPTO`).
- **Наскрізний растровий PDF-OCR пайплайн із динамічним розрахунком дельти та геометричними координатами `bbox`**: по-гліфове розпізнавання значень у `docs/pdf-scan-ocr-engine.js` без підстановки еталонних констант і жорстка відмова (`REJECTED_UNSUPPORTED_OR_CORRUPTED_SCAN`) на пошкоджених або непідтримуваних PDF.
- **Криптокапсула `#diag=` із 128-бітним CSPRNG секретом (32 hex-символи)**: генерація унікального ефемерного ключа через `crypto.getRandomValues(new Uint8Array(16))`, перевірка HMAC-SHA256 у константному часі перед розшифруванням `AES-256-GCM`, потокові ліміти декомпресії (`4 MB` / `16 MB` / `32 MB`) та атомарне відновлення стану в Cockpit.
- **Чотиристовпцева матриця «Спочатку проблеми» (`Параметр | Результат / статус | Джерела | Наступна дія`)**: сортування за пріоритетом критичності, перемикач фільтра приховування `PASS`, нерозривні числові значення з одиницями (`.num-unit`) та повна клавіатурна навігація з поверненням фокуса.
- **Відтворюваний живий бенчмарк на 15 випадків (`12 відкритих зразків + 1 растровий PDF-скан + 2 негативні контролі`)** та двошаровий тестовий контур (Vitest + Ajv JSON Schema з 12 негативними мутаціями + Playwright Chromium E2E).

## [2.2.0] - 2026-10-19

### Додано
- **Нативний крос-документний двигун `engines/defdoc_ai/defdoc_auditor.py` та `document_intake.py` (v2.2)**: прямий розбір таблиць і параграфів `.docx` (`w:tbl`, `w:p`) та аркушів `.xlsx` (`sharedStrings.xml`, `sheet*.xml`) через стандартну бібліотеку Python без зовнішніх залежностей, зі статусами `PASS` / `FAIL` / `UNVERIFIED`.
- **Демонстраційне вирівнювання синтетичного пакета (`--apply-fixes-from-bundle`)**: навчальний режим для синтетичного прикладу `--self-test`, який демонструє механічну синхронізацію XML-вузлів між тестовими шаблонами ТУ, Паспорта та ПМВ (`49/100 · BLOCKED` → `100/100` у синтетичному демо; не замінює реальні випробування чи підписи комісії та заблокований для клієнтських входів).
- **Мультиформатний аналізатор якості журналів телеметрії `engines/telemetry_ew/telemetry_analyzer.py`**: локальний структурний розбір та описова статистика полів для логів ArduPilot DataFlash (`.bin`), PX4 ULog (`.ulg`), u-blox (`.ubx`), MAVLink v1/v2 (`.tlog`/`.mavlink`), NMEA-0183 (`.nmea`), CSV (`.csv`) та `.gz` із перевіркою контрольних сум, типів часу та пропусків (без непідтверджених причинних вердиктів про РЕБ).
- **Допоміжні утиліти токенізації та зсуву координат (`sanitize_doc.py`, `sanitize_telemetry.py`)**: локальна regex-токенізація текстових полів документів та фіксований зсув координат для підтримуваних схем логів (потребує ручної перевірки інженером перед передачею файлів).
- **Оновлений український інтерактивний стенд (`site/index.html`)**: 3 робочі контури в одному інтерфейсі (звірка таблиць ТУ ⇄ Паспорт ⇄ ПМВ, інспекція бінарних заголовків телеметрії `.bin`/`.ulg`/`.ubx`/`.nmea`, локальна перевірка власного файлу у браузері).

### Видалено
- Прибрано застарілі демонстраційні відео-скрипти та важкі медіафайли на користь миттєвого інтерактивного стенду у браузері та детермінованих CLI-перевірок.
