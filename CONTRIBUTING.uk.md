# Внесок у проєкт

*[English](CONTRIBUTING.md) · Українською*

Дякуємо за вдосконалення UAV Readiness & Evidence Copilot.

Цей проєкт — це безпечне, публічне портфоліо-демо для контролю якості документації (documentation QA), відстеження доказів (evidence tracking), простежуваності (traceability) та звітності про готовність (readiness reporting).

## Безпечний обсяг внесків

Дозволено:

- покращення якості документації;
- покращення синтетичних демонстраційних даних;
- покращення парсера (parser), схеми (schema), доказів (evidence), правил (rules), звіту (report) та тестів (tests);
- покращення презентації портфоліо;
- уточнення меж безпеки (safety boundary).

Не дозволено:

- операційні функції керування БпЛА (UAV control);
- інтеграції з реальним керуванням;
- обробка даних живих систем;
- генерація маршрутів (route) чи точок маршруту (waypoint);
- робота з корисним навантаженням (payload);
- підтримка наведення (targeting);
- тактичні поради.

## Перевірки під час розробки

Перед відкриттям запиту на злиття (pull request) виконайте:

```powershell
npm run demo:readiness
npm run typecheck
npm test
npm audit --audit-level=moderate
```

## Правило доказів

Основне правило:

```text
No evidence -> locked.
```

Не позначайте твердження як підтверджені (verified), якщо в безпечних демонстраційних даних або тестах немає підтверджувальних доказів.
