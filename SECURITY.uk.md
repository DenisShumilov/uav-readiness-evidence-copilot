# Політика безпеки

*[English](SECURITY.md) · Українською*

## Обсяг проєкту

Цей репозиторій (repository) є безпечним офлайн-портфоліо-проєктом для контролю якості документації (documentation QA).

Він не потребує API-ключів (API keys), хмарних облікових даних (cloud credentials), доступу до реального обладнання чи живих інтеграцій (live integrations).

## Повідомлення про проблеми

Якщо ви знайшли проблему безпеки, відкрийте issue (звернення) на GitHub із зазначенням:

- зачепленого файлу або робочого процесу (workflow);
- що може піти не так;
- кроків для відтворення лише на синтетичних даних (synthetic data);
- запропонованого безпечного виправлення, якщо воно відоме.

Не включайте у публічні звернення секрети (secrets), приватні дані, реальні операційні дані чи конфіденційні відомості про систему.

## Межі безпеки

Цей проєкт має залишатися обмеженим контролем якості документації (documentation QA), відстеженням доказів (evidence tracking), простежуваністю (traceability), тестуванням і звітуванням.

Не додавайте функції для:

- операційного керування БпЛА (UAV — безпілотний літальний апарат);
- інтеграцій із керуванням у реальному світі;
- обробки даних живих систем;
- генерації маршрутів або точок маршруту (route or waypoint generation);
- роботи з корисним навантаженням (payload);
- підтримки наведення на ціль (targeting);
- тактичних порад.

## Перевірка залежностей

Перед публічним випуском або зміною залежностей (dependencies) виконайте:

```powershell
npm audit --audit-level=moderate
```

Тримайте залежності мінімальними. Надавайте перевагу локальному коду й тестам, а не зайвим зовнішнім інструментам.
