# Словник понять

*Українською · [English](glossary.en.md)*

Це стислий інженерний словник термінів проєкту та стенду перевірки.

## Основні поняття

- **manual** — інструкція або технічний паспорт виробу чи вузла.
- **pinout** — таблиця призначення контактів роз'єму або плати.
- **BOM** — Bill of Materials, відомість комплектації та складових частин.
- **TDP** — Technical Data Package, технічний пакет даних: упорядкований набір конструкторських і експлуатаційних записів.
- **STANAG** — NATO Standardization Agreement, стандарт сумісності НАТО.
- **config dump** — вивантаження параметрів конфігурації бортового або стендового контролера.
- **evidence** — верифікований доказ (запис у протоколі, таблиці, бінарному логу або сертифікаті).
- **evidence graph** — граф доказів: детермінована структура зв'язків між інженерними твердженнями та їх першоджерелами.
- **traceability** — простежуваність за ланцюжком «вимога → доказ → перевірка → статус».
- **parser** — модуль побайтового або структурного розбору вхідного файлу.
- **schema** — формальна специфікація структури та типів даних (JSON Schema / Zod).
- **fixture** — еталонний тестовий файл для відтворюваної інженерної верифікації.
- **artifact** — вхідний документ, бінарний лог або згенерований звіт перевірки.
- **readiness score** — детермінована оцінка готовності пакета доказів за шкалою `0–100`.
- **QA** — інженерна верифікація якості та цілісності даних.
- **CLI** — інтерфейс командного рядка для пакетного запуску та CI/CD.
- **locked** — заблокований пункт через відсутність підтвердного доказу або провал тесту (`No evidence → locked`).
- **conflict** — пряма числова або ревізійна суперечність між двома документами (`CONFLICT_CEILING = 49`).
- **synthetic** — синтетичний навчально-тестовий набір даних без реальних чутливих відомостей.
- **OOXML** — Open Packaging Conventions (`.docx`, `.xlsx`): ZIP-архів із XML-деревом тексту, таблиць, формул і ревізій.
- **SI vector (7D)** — 7-вимірний вектор фізичних розмірностей Міжнародної системи одиниць $[M, L, T, I, \Theta, N, J]$ для перевірки сумісності фізичних величин.
- **DataFlash / ULog / MAVLink / UBX** — бінарні протоколи польотної телеметрії та супутникової навігації (`ArduPilot`, `PX4`, `u-blox`).
- **ASN.1 DER / CMS SignedData** — бінарний формат криптографічних контейнерів кваліфікованого електронного підпису (`.p7s`, `ДСТУ 4145-2002`).
- **CEP (СКВ)** — серединне кругове відхилення точки приземлення або навігаційної оцінки.
- **SHA-256 / AES-256-GCM** — криптографічне хешування цілісності артефактів та автентифіковане шифрування звітів.
- **SARIF 2.1.0** — стандартний JSON-формат результатів статичного аналізу для інтеграції у CI-системи.

## Правило прозорості термінів

Під час формування інженерних звітів кожне технічне скорочення або код дефекту супроводжується чітким поясненням фізичного або нормативного змісту:

`locked (пункт заблоковано: відсутнє посилання на первинний протокол випробувань)`
