# Explain Terms

Use this skill whenever a response contains technical terms.

Rule:

Explain the term immediately in parentheses.

Example:

`parser (код, який читає файл і дістає з нього дані)`

Important terms:

- manual = інструкція або технічний паспорт;
- pinout = карта контактів;
- BOM = список деталей;
- config dump = файл із налаштуваннями;
- evidence = доказ;
- evidence graph = карта доказів;
- traceability = зв'язок "вимога -> доказ -> перевірка";
- parser = код, який читає файл;
- schema = правила структури даних;
- fixture = навчальний тестовий файл;
- artifact = файл, який завантажили або згенерували;
- readiness score = оцінка готовності;
- QA = перевірка якості;
- CLI = командний рядок;
- repo = папка проєкту з Git;
- package = модуль проєкту;
- subagent = окремий помічник з роллю;
- skill = готова інструкція для агента;
- red-team = критична перевірка ризиків;
- self-review = самоперевірка;
- locked = заблоковано, бо нема доказу.
