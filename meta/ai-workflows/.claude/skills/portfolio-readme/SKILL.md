# Portfolio README

Use this skill when writing or reviewing README and portfolio docs.

The README must make clear:

- this is a UAV QA and evidence project;
- this is not drone control;
- this is not mission planning;
- this uses synthetic demo data;
- the key idea is "No evidence -> locked";
- the project is understandable in 30 seconds.

Explain terms in simple Ukrainian.

Avoid hype. Show engineering discipline.
