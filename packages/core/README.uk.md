# packages/core

*[English](README.md) · Українською*

> Спільні схеми TypeScript/Zod (схеми даних) і безпечні синтетичні приклади для моделі даних готовності документації.

Частина монорепозиторію [UAV Readiness & Evidence Copilot](../../README.md).

## Що містить

- Схеми Zod для артефактів, джерел доказів (evidence sources), тверджень (claims), зв'язків (links) і блокувань (locks)
- Елементи контролю якості (QA items), рядки трасування (traceability rows) і форми звіту про готовність (readiness-report)
- форму демонстраційного набору (demo-bundle) та безпечні синтетичні приклади даних

## Межі безпеки

Схеми описують лише форми документації/паперової роботи — ніколи операційні системи. `No evidence → locked`.
