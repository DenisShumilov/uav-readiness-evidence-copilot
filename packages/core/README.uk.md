# packages/core

*[English](README.md) · Українською*

> Спільні схеми TypeScript/Zod (схеми даних) для моделі даних готовності документації.

Частина монорепозиторію [UAV Readiness & Evidence Copilot](../../README.uk.md).

## Що містить

- Схеми Zod для артефактів, джерел доказів (evidence sources), тверджень (claims), зв'язків (links) і блокувань (locks)
- Елементи контролю якості (QA items), висновки готовності (readiness findings) і форму демонстраційного набору (demo-bundle)
- перевірки конфліктів ревізій між документами для QA документації

## Межі безпеки

Схеми описують лише форми документації/паперової роботи — ніколи операційні системи. `No evidence → locked`.
