# packages/core

*[English](README.md) · Українською*

Спільні схеми TypeScript/Zod (схеми даних) і безпечні синтетичні приклади для моделі даних готовності документації.

Цей пакет визначає дозволені форми (структури) для артефактів, доказів (evidence), блокувань (locks), елементів контролю якості (QA items), рядків трасування (traceability rows), звітів про готовність і демонстраційних наборів (demo bundles).
