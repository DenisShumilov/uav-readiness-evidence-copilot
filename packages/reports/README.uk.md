# packages/reports

*[English](README.md) · Українською*

> Генератори звітів та експорту (export — вивантаження даних) для безпечного демонстраційного процесу.

Частина монорепозиторію [UAV Readiness & Evidence Copilot](../../README.uk.md).

## Що містить

- Звіт про готовність у форматі Markdown (markdown — спрощена мова розмітки тексту)
- демонстраційна сторінка портфоліо (двомовний HTML)
- матриця простежуваності (traceability matrix — таблиця відповідності вимог) у форматі CSV
- маніфест хешів артефактів (hash manifest — перелік контрольних сум файлів)
- експорт знахідок у форматі SARIF 2.1.0 (SARIF — стандартний формат результатів статичного аналізу)

## Межі безпеки

Звіти описують лише готовність документації — ніколи не операційну готовність.
