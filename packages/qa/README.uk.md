# packages/qa

*[English](README.md) · Українською*

> Наскрізні димові тести (smoke tests — базові перевірки працездатності) для демонстраційного процесу CLI (command-line interface — інтерфейс командного рядка) оцінки готовності.

Частина монорепозиторію [UAV Readiness & Evidence Copilot](../../README.md).

## Що містить

- Перевіряє, що демонстраційна команда генерує очікуваний звіт, граф доказів (evidence graph — граф зв'язків доказів), оцінку готовності, матрицю простежуваності (traceability matrix — таблиця відповідності вимог), хеші артефактів (artifact hashes — контрольні суми файлів), SARIF (формат звітів статичного аналізу) та вихідні матеріали демонстрації портфоліо
- Стверджує, що згенерований звіт залишається в межах безпечних формулювань

## Межі безпеки

Тести захищають межі контролю якості документації (documentation QA — перевірка якості документації) та відхиляють небезпечні операційні формулювання. `No evidence → locked`.
