# packages/qa

*[English](README.md) · Українською*

Димові тести (smoke tests — базові перевірки працездатності) для демонстраційного процесу CLI (інтерфейс командного рядка) оцінки готовності.

Цей пакет перевіряє, що демонстраційна команда генерує очікуваний звіт, граф доказів (evidence graph), оцінку готовності, матрицю трасування (traceability matrix), хеші артефактів та результати демонстрації для портфоліо.
