# Phase Review

Use after each phase.

Check:

- What changed?
- Did it help the portfolio?
- Is it safe to show publicly?
- Did it stay inside MVP?
- Did it avoid drone control and mission tooling?
- Are terms explained simply?
- What is the next small step?

Output:

1. Summary
2. Risks
3. Beginner explanation
4. Next small step
