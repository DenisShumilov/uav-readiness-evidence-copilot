What it does

  • Reads safe synthetic demo files.
  • Builds a map of claims and evidence.
  • Shows verified, partial, and locked items.
  • Generates reports, traceability CSV, hashes, and a static demo page.

What it does not do

  • No drone control.
  • No live telemetry processing.
  • No route or waypoint generation.
  • No payload, targeting, or tactical workflows.

Safety boundaries

This is a documentation QA workflow for engineering review. All data is synthetic, static, and educational.
